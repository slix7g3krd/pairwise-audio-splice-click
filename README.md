# pairwise-audio-splice-click

剪辑点落在波形半山腰，导出后每次播放都有一声轻响，切点两侧的采样值不连续；交叉淡化只做了增益线性过渡，两段相位相反的噪声叠加后出现空洞；素材有直流偏移，切点处电平跳变；采样率不同的两段直接拼接，重采样滤波器在边界没预热；剪辑软件按毫秒取整，实际切点在样本之间，导出时四舍五入到错误样本；循环片段首尾各淡出 5 毫秒，循环时中间出现一个凹陷；增益归一化在拼接前做，拼接后整体又超限；时间线有 48k 与 44.1k 混合素材，监听用 48k 导出用 44.1k，切点位置漂移；淡入淡出曲线用线性，听觉上仍有突变；导出格式带预滚，播放器从预滚帧开始解码，第一帧被重复。media/audio_splice_click.py 是核心，tests/test_audio_splice_click.py 15个红。要修的是：切点等功率交叉淡化；相位对齐；去直流；重采样预热；按样本取整；循环首尾匹配；拼接后再归一；统一工程采样率；等功率曲线；预滚处理。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
